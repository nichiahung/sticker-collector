# 產品使用說明（使用者手冊）

> 對象：家長（大人端）＋ 4–9 歲孩子（小孩端）。

## 兩個入口
- **大人端**：開 `http://<host>:<port>/`（預設）
- **小孩端**：開 `http://<host>:<port>/?view=kid`（例如把平板交給孩子時）

## 大人怎麼用
1. **記貼紙（每天）**：開大人端→預設停在「記」分頁→上回選的孩子與貼紙類型已記住→按大「＋記」＝1 下記完。要換類型按 chip（各 1 下）。
2. **配置（一次）**：「目錄」分頁→加貼紙種類（名稱/圖示/分值/稀有度）、加獎品（三價位：快達/幾週/長期）、加孩子。
3. **記帳（隨時）**：「明細」分頁→收受與兌換紀錄。

### 貼紙怎麼分（稀有度）
common（1–2 分，日常）／rare（3–4 分）／epic（5 分，大成就）。**貼紙綁「做到什麼」，不綁「乖不乖」**：例如「準備好用品＋1」「作業全對＋5」。

### 獎品怎麼兌
獎品分三價位。建議**兩週開一次店**集中兌換（稀缺節奏）；商品放文具小物，不放錢/遊戲類。

## 小孩怎麼用
1. 大人把平板交給他→開小孩端→封面「○○的貼紙本」→「開始看」
2. 先看「新的一張」（大人剛記的那張）
3. 翻貼紙冊（‹ › 或滑動）：彩色的＝已貼、灰階 ?＝還缺的、金框＝集很多張的、整頁集齊所有種→封面頭像變金環（全集成就）
4. 右上 🔒＝請大人開啟（唯一出口，按就回給大人）

## FAQ
- **孩子把別的小孩分數看到嗎？** 不會。每個入口只看自己的。
- **記錯了怎麼刪？** 大人端明細分頁逐筆刪。
- **孩子問「集滿有什麼用」？** 引導他看「離獎品幾格」，讓他自己選一個快達獎品當目標。
